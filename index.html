SWAB Event Day Explorer

We only get one shot at event day each year. 2026 was the first year we ran it on our own check-in and checkout software, so for the first time we have a record of how the day actually went.

This site lets you go back through that day. Use it when planning the next one: how many mentors each shift really needs, when the lines started to build, where kids and mentors ended up waiting. We'll add each new event day here so we can compare year to year.
